# Student Study Hub

**Share and find study notes easily.**

Student Study Hub is a web application designed to help students create, organize, manage, and share study notes.

## Live Application

[Vercel Deployment](https://wdd430-student-study-hub.vercel.app/)

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS

- NextAuth.js
- bcryptjs

## Main Features

- User registration
- User login
- Student dashboard
- Study notes management
- Note creation and editing
- Note organization

*Some features are still undergoing testing and development.*

## Database

The application uses Neon PostgreSQL.

The main database tables are:

- **Users:** Stores user account information.
- **Notes:** Stores study notes and their ownership information.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/bennyasi/wdd430-student-study-hub.git
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file and configure the required environment variables privately.

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
